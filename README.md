# 메뉴얼 프로그램 사용 설명서

## 1. 준비
- 지원 브라우저: Edge, Chrome
- 설치 불필요. `index.html`을 Edge/Chrome으로 열면 실행됨(`file://`).
- 폴더 구성: `index.html`, `css/`, `js/`, `helper/`(첨부 열기 도우미), 블록 데이터 폴더(예: `Data/`).

## 2. 시작하기
1. `폴더 열기`로 블록 JSON 파일이 있는(또는 저장할) 폴더를 선택.
2. 다음 실행부터는 `마지막 폴더 다시 열기`로 같은 폴더를 바로 열 수 있음(권한 허용 필요).

## 3. 화면
- 왼쪽: 폴더 이름, `+ 새 블록`, 검색창, 카테고리 칩, 블록 목록.
- 가운데: 선택한 메인 블록 1개만 표시. 블록 안의 행이 세로 노선(본선)에 핀으로 연결됨.
- 상단: `← 이전`(블록 이동 이력), 경로 표시, 테마 전환.
- 행 유형: 절차(흰 원) / 조건(노란 마름모) / 주의(빨간 원) / 특이사항(보라 원).

## 4. 검색
- 카테고리 칩: 여러 개 선택 시 모두 가진 블록만 표시(AND).
- 검색창: 공백으로 구분한 단어를 모두 포함하는 블록만 표시(AND). 제목, 카테고리, 행 내용, 분기 라벨, 첨부 이름을 검색.
- `필터 해제`로 초기화. 결과 건수가 함께 표시됨.

## 5. 블록 참조(연결)
- 행 아래 분기선 끝의 칩을 누르면 화면 전환 없이 그 자리에 참조 블록이 펼쳐짐. 다시 누르면 접힘.
- 펼친 블록의 `메인으로 열기`로 해당 블록을 메인으로 전환. `← 이전`으로 되돌아감.
- 대상 블록이 삭제된 경우 `(블록 없음)`, 순환 참조는 `(순환 참조)`로 표시되며 펼쳐지지 않음.

## 6. 블록 작성·수정·삭제
1. `+ 새 블록` 또는 메인 블록의 `편집`.
2. 제목, 카테고리(쉼표로 구분), 내용 행을 입력. 행마다 유형 선택, `↑`/`↓` 순서 변경, `행 삭제`.
3. `+ 분기 연결`: 분기 라벨과 연결할 블록 선택(연결 없음도 가능). 조건 행에 여러 분기를 넣어 경우별 이동을 표현.
4. `저장`하면 `<블록ID>.json` 파일로 폴더에 저장됨. 삭제 시 파일이 삭제되며, 이 블록을 참조하는 블록이 있으면 목록을 보여 줌.
- 내용이 비어 있고 분기·첨부도 없는 행은 저장 시 제거됨.

## 7. 첨부파일
첨부는 내용 행 단위로 붙음.
1. 편집기 아래 `+ 기준 폴더 추가`로 첨부 파일이 있는 최상위 폴더를 등록(2개 이상 가능).
   - 브라우저가 파일의 실제 경로를 알려 주지 않으므로, 폴더 선택 후 전체 경로가 필요함.
   - 이 앱과 같은 폴더 계층 안에 있으면 경로를 자동 추정해 확인만 받음. 아니면 탐색기 주소창의 경로를 입력.
2. 행의 `+ 첨부 (파일 선택)`에서 파일을 선택. 선택한 파일이 속한 기준 폴더를 자동 판별해 경로를 저장.
3. 등록된 기준 폴더 하위가 아닌 파일은 첨부되지 않음. 해당 폴더를 먼저 등록.
- 기준 폴더 등록 정보는 이 브라우저에만 저장됨(PC마다 등록). 블록 JSON에는 파일 경로(`file:///...`)만 저장됨.

## 8. 첨부 열기 도우미(PC마다 1회)
브라우저는 로컬 파일을 연결 프로그램으로 직접 실행할 수 없음(txt는 브라우저에 표시, Word/PPT는 다운로드). 이를 위해 `ohmyopen:` 링크를 처리하는 도우미를 등록함.
1. `helper\register.cmd`를 더블클릭해 1회 실행(관리자 권한 불필요, 현재 사용자 레지스트리에 등록).
2. 첫 첨부 클릭 시 Edge의 확인 창에서 `항상 허용` 선택.
3. 이후 첨부 클릭 시 확장자에 연결된 프로그램으로 열림(txt → 메모장, docx → Word 등).
- 폴더를 옮기면 `register.cmd`를 다시 실행. 해제는 `helper\unregister.cmd`.
- 보안상 실행 파일·스크립트류(exe, bat, cmd, ps1, vbs, js, msi, lnk 등)는 열리지 않음. 존재하지 않는 파일은 오류 창 표시.
- 업무망 정책이 레지스트리 쓰기 또는 Windows Script Host(wscript)를 막으면 동작하지 않음.

## 9. 테마
상단 `테마` 버튼으로 다크 → 라이트 → 저자극 순서로 전환. 선택값은 이 브라우저에 저장됨. 글자 크기는 브라우저 확대/축소(Ctrl + 마우스 휠)를 사용.

## 10. 데이터 공유와 백업
- 블록 폴더 전체를 복사하면 그대로 이전됨. 공유 폴더에 두고 여러 PC에서 같은 폴더를 열 수 있음.
- 동시에 같은 블록을 편집하면 나중에 저장한 내용이 덮어씀.
- 읽지 못한 파일이 있으면 목록 아래에 개수가 표시되며(마우스를 올리면 파일명), 형식이 맞지 않는 JSON일 때 발생.

## 11. 문제 해결

| 증상 | 확인 사항 |
|---|---|
| `폴더 열기`가 동작하지 않음 | Edge/Chrome 사용 여부. Brave는 미지원. |
| 마지막 폴더 권한이 거부됨 | `폴더 열기`로 다시 선택. |
| 첨부 파일 선택 후 추가되지 않음 | 파일이 등록된 기준 폴더 하위인지 확인. |
| 첨부 클릭 시 반응 없음 | `register.cmd` 실행 여부, Edge 확인 창에서 `항상 허용` 선택 여부. |
| 첨부 클릭 시 "File not found" | 기준 폴더 경로 입력 오류 또는 파일 이동. `경로 수정`으로 보정. |
